# TECH 36: Vibe Coding Resources

Assignment steps, prompts and plain-language notes for **TECH 36: Vibe Coding**, a Stanford Continuing Studies course taught by Ray Villalobos.

Vibe coding means building software by describing what you want in plain language and letting an AI write the code. You don't need to know how to program. If you can write a prompt for ChatGPT, you can take this class.

## How to use this repo

- **Start with the week you're on.** Each week has a folder with a `README.md` that explains the big ideas in plain words, then walks through that week's assignment step by step.
- **Copy prompts from `prompts.md`.** Every week has a `prompts.md` file with all of the suggested prompts in one place. They're suggestions. Rewrite them, combine them, or skip them. Replace anything in `[square brackets]` with your own details.
- **The course site is the official version.** Due dates and submission boxes live in Canvas. If something here and Canvas disagree, follow Canvas.
- **Never paste secret keys or real passwords into an AI chat.** That rule applies every week.

## About the DRAFT files

Files with **DRAFT** in the name are proposed additions to Assignments 4 and 5: a security test, a ship pages and repo files prompt, and a privacy and data check. **They are pending the instructor's approval and are not part of the official assignments yet.** They may change or be removed. Each one has a banner at the top that says so. Until they're approved, follow the assignment steps in each week's `README.md`.

## Helpful sites from the course

- [VibeIt](https://vibeit.work): where you publish and catalog everything you build in the course
- [Vibe Glossary](https://vibeglossary.com): plain-language definitions of web and AI terms, with live examples and quizzes
- [MVPunk](https://mvpunk.com): turns an idea into a plan your AI can build from
- Places to find data: [data.gov](https://data.gov), [Kaggle](https://www.kaggle.com/datasets), [Google Dataset Search](https://datasetsearch.research.google.com), [World Bank](https://data.worldbank.org), [FiveThirtyEight](https://github.com/fivethirtyeight/data)
